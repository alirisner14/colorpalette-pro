# Roadmap

## 1.0: Web (built)
- [x] Color, Photo, Theme and Build modes
- [x] Harmony filter, 2 of each by default, adjustable palette count
- [x] HEX and RGB on every color, with copy
- [x] Exports to 12 formats covering Procreate, Adobe, Affinity, GIMP/Krita, Sketch, Figma/Canva and the web
- [x] Flipbook swatch book with tabs, drag and drop, and a full-screen viewer
- [x] Liquid-glass UI

## Next: high value, low effort
- [ ] **Back up and restore the swatch book** to a single file. This answers the biggest support risk: clearing site data wipes the book.
- [ ] **Import palette files** (`.ase`, `.aco`, `.gpl`, `.swatches`) into the swatch book
- [ ] Self-host the fonts for a fully offline first launch, and drop the Google Fonts paragraph from the privacy policy
- [ ] **Lock colors** so they survive a shuffle
- [ ] Drag to reorder colors inside a palette
- [ ] Search in the swatch book

## Ideas that set it apart
- [ ] **Accessibility checker:** WCAG contrast for every color pair, and which pairs are safe for text
- [ ] **Colorblind preview:** see a palette as people with protanopia, deuteranopia or tritanopia do
- [ ] **Palette in context:** preview a palette on sample art (a quilt, a room, an outfit, a logo, a web page)
- [ ] **Printable paint-chip sheets:** a PDF of chips to cut out and keep
- [ ] **Gradients** generated from any palette, exported as CSS or image
- [ ] **Palette of the day** with a gentle streak
- [ ] **Mood from a word:** type "rainy café" and get a palette
- [ ] **Share link / QR code:** palette data encoded in the URL, so there's no server

## 2.x: Mobile
- [ ] iOS and Android apps with Capacitor (see [MOBILE.md](MOBILE.md))
- [ ] Pick colors live from the camera
- [ ] Native files and share sheet for exports
