## File formats and code

The export and import formats (Procreate `.swatches`, Adobe Swatch Exchange
`.ase`, Photoshop `.aco`, GIMP `.gpl`, Sketch `.sketchpalette`, Paint.NET
palette, SVG, CSS and JSON), the PDF writer, the zip reader and writer, and
the QR code encoder are all written by us, from publicly documented file
structures and standards. **No third-party code library is included in the
app.** The app has no runtime dependencies.

## Example artwork and printable layouts

The example artwork ("Palette in context": mandala, sunset hills, flower
vase, patchwork quilt and the others), the swatch deck and book layouts, and
the printable templates are original work by us. Their terms are in the EULA.
