The export formats (Procreate `.swatches`, Adobe Swatch Exchange `.ase`,
Photoshop `.aco`, GIMP `.gpl`, Sketch `.sketchpalette`, Paint.NET palette, SVG,
CSS and JSON) are written by our own code, from publicly documented file
structures. No third-party code is included to produce them.
